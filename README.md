# 育儿嫂工资计算器

当前稳定版本：V3.0

## 核心规则

- 固定月薪：7000元，不分大小月。
- 工资周期：每月18日至次月17日，起止日期均计入。
- 本期应休天数：等于该工资周期内实际出现的周六数量。
- 普通休息日可以安排在周六、周日或其他日期。
- 程序只比较整个工资周期内“本期应休总天数”和“实际普通休息总天数”。
- 不按周判断，不设置跨周结转，也不限制某一周最多休几天。
- 实际普通休息少于应休天数时，按基本日工资补发；多于应休天数时，按基本日工资扣减。
- 法定节假日带薪休息单独统计，不占普通休息额度。
- 法定节假日上班按设置的节假日倍数计算加成。
- 国家统一安排的补班日不影响育儿嫂排班，不录入、不参与计算。

## 示例

2026年7月18日至2026年8月17日共有5个周六，因此本期应休5天。只要本周期实际普通休息合计也是5天，无论具体休在哪几天，固定工资仍为7000元。

## 数据说明

所有排班、工资设置和自定义节假日保存在当前浏览器的本地存储中。删除桌面图标通常不会删除数据，但清除Safari网站数据会导致本地记录丢失。建议定期使用程序内的“导出全部备份”。

## 年度节假日维护

程序内置2026年法定节假日。后续年度的正式节假日日期公布后，只需在程序中补充对应日期，无需修改工资算法。
